# Visual track · Session 3 · VPS deployment: headline outline

Deck: [`decks/session-3-vps-deployment-visual.html`](../../decks/session-3-vps-deployment-visual.html)

These titles shipped with PR #7 and were already full-sentence assertions. They are unchanged.

The spine is prerequisites → worked example → practice → check.

1. Your complete Financial App will run on the VPS.
2. Your server account and your app login serve different purposes.
3. Each participant deploys within their own assigned space.
4. HTTPS connects the browser to your frontend and backend.
5. The backend still calls the external APIs and LLM.
6. Secrets stay on the server, outside browser code and Git.
7. Database and Wiki files must survive code updates.
8. Inspect the app and approve a deployment plan first.
9. Transfer the code and a consistent snapshot of your data.
10. A Python environment runs the backend without Docker.
11. A managed service keeps the backend running after logout.
12. Your assigned HTTPS address serves the built website.
13. Test login, permissions, API calls and Wiki-backed answers.
14. Logs and backups help you recover a failed deployment.
15. Your practice deploys and verifies your own app.
16. Finish by opening your working app from another device.
