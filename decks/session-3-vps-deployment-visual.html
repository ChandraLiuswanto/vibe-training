## Before practice — facilitator prerequisites

Shared Ubuntu/Debian VPS: separate accounts, adequate private disk/memory quotas, assigned loopback ports, release/data/config paths and separate proxy-readable static directories. Supply a verified SSH host-key fingerprint and prepared HTTPS URL/base path for each participant. No participant root/sudo or shared proxy/firewall edits.

Prepare SSH/SFTP, compatible Python and venv tooling, per-user systemd managers with lingering, user-service naming, certificates, SPA fallback/API proxy routes and any LLM streaming/timeouts. Prefer distinct hostnames; path prefixes require deliberate base/API/cookie setup.

Fill deployment-card.json with non-secret assignments. Blank/missing assignments block deployment. Never put credentials in this card. Participants authenticate in their trusted terminal/key agent and verify host keys through the facilitator.
